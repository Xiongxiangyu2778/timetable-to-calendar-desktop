# 课表转日历（早八自动化）

把教务系统的课表，转成手机日历能直接导入的 `.ics` 文件。

**苹果 iPhone、安卓（Google 日历 / 小米 / 华为 / OPPO / vivo / 三星）、Windows Outlook 全部支持。**

## 四种用法

| 模式 | 适合 | 需要什么 |
|---|---|---|
| **网页版（最省事）** | 没电脑、想分享给别人 | 手机浏览器打开 [在线地址](https://xiongxiangyu2778.github.io/timetable-to-calendar/)，支持 Excel / CSV / **PDF** |
| **全自动（电脑）** | 教务系统是网页表格 | Windows + Node.js + Python |
| **PDF 直接转（电脑）** | 教务系统只能导出 PDF | Windows + Python + `pip install pymupdf openpyxl` |
| **手动填文本** | 课表是截图 / 特殊控件 | Windows + Python |

> 网页版源码在另一个仓库：[timetable-to-calendar](https://github.com/Xiongxiangyu2778/timetable-to-calendar)

## PDF 课表怎么用（新）

**最快：把 PDF 拖到 `一键-生成日历.bat` 上**，然后补一句开学日期：

```bash
python 课表转日历.py 教务课表.pdf --start 2026-09-07
```

`--start` 填校历第一周的周一；如果同目录已有 `课表.txt` 且里面写了 `学期开始:`，可以省略，会自动沿用。

**想先看一眼识别对不对 / 想要 Excel：**

```bash
python pdf转表格.py 教务课表.pdf              # 同目录生成 课表.csv + 课表.xlsx + 课表_课表.txt
python pdf转表格.py 教务课表.pdf -o 输出目录
```

| 产物 | 用途 |
|---|---|
| `课表.csv` | 双击用 Excel / WPS 打开，就是「节次 × 星期」排好的表格 |
| `课表.xlsx` | 两张表：「课表」原样版面 +「课程明细」一门课一行，方便筛选核对 |
| `课表_课表.txt` | `课程名 \| 星期 \| 节次 \| 周次 \| 教室 \| 教师`，改完开学日期直接喂给 `课表转日历.py` |

识别原理（PDF 里没有表格，只有文字 + 坐标）：

1. 按 y 坐标把文字聚成「行」；
2. 找含「星期一~星期日」的那行当表头，用每个表头字的 x 中心算出列边界（表头若写成「一/二/三」，就走框线表格识别）；
3. 左边节次列的「1-2」「第 3 节」当作行锚点；
4. 把每列文字聚成格子，按格子中心离哪个节次锚点最近，判断它属于第几节；
5. 格子里再拆出 课程名 / 教室 / 教师 / 周次。

> ❌ **扫描件 / 图片版 PDF 不支持**（里面没有文字层）。会明确提示，不会瞎猜。办法：用 WPS「另存为 Excel」、或用网页版「粘贴文字」。

## 全自动模式怎么用

1. 安装依赖（只需一次）：
   ```bash
   npm install playwright-core
   ```
2. 双击 **`一键-抓取并生成.bat`**
3. 脚本自动打开独立浏览器（第一次需登录教务系统，之后记住登录状态）
4. 进入「我的课表」页面，确保能看到 **星期一 ~ 星期日** 那张表
5. 脚本自动识别表格 → 抓成 `课表_抓取.txt` → 生成 `我的课表.ics`
6. 把 `.ics` 发到手机导入

> 脚本**不接触账号密码**：连接的是你已经登录的浏览器窗口，只读取页面表格。所有数据都在本机处理。

### 支持范围

- ✅ 标准 HTML 表格课表（正方、强智、URP、青果等大多数教务系统）
- ✅ **iframe 内嵌课表**（强智等系统把课表放在子页面里也能找到）
- ✅ **大节版式**（一行「第一二节」= 两节课，自动拆成 1-2 节）
- ✅ 合并单元格（rowspan / colspan）、单双周、连堂、多门课挤在同一格
- ✅ **自动识别学期与当前周次**，自动算出第一周周一（不用手填开学日期）
- ❌ 纯图片课表（截图/照片）暂不支持，请用手动模式
- ❌ 需要拖动/点选才显示课程的 Flash 式页面不支持

## 手动模式怎么用

打开 `课表.txt`，按注释格式填：

```
学期开始: 2026-09-07

高等数学 | 周一 | 1-2 | 1-16 | 教1-101 | 张老师
大学英语 | 周二 | 3-4 | 1-16单 | 外语楼203 | 李老师
```

- 星期：`周一` / `星期一` / `1` 都行
- 节次：`1-2`（连堂）、`3,4`、`5`
- 周次：`1-16`（每周）、`1-16单`（单周）、`2-16双`（双周）、`1,3,5,7`
- 教室、教师可留空，但分隔符 `|` 要保留

然后双击 `一键-生成日历.bat`。

## 导入方法

| 设备 | 步骤 |
|---|---|
| **iPhone** | 微信里点开 `.ics` → 右上角「…」→ 用其他应用打开 → 选「日历」→ 全部添加 |
| **安卓（Google 日历）** | 网页版 calendar.google.com → 设置 → 导入和导出 → 选择 `.ics` 导入 |
| **安卓（小米/华为/OPPO/vivo/三星）** | 文件管理里点开 `.ics` → 选择「日历」导入；或在日历 App 里找「导入日程」 |
| **Windows** | 双击 `.ics` → 自动导入 Outlook / 系统日历 |
| **Mac** | 双击 `.ics` → 日历 App → 添加 |

> 建议导入到一个**单独的日历分组**（如「课表」），课表变了可以整组删除再导入，不会误删别的日程。

## 常见问题

**Q：为什么每节课都是一条独立事件，而不是重复事件？**
为了让所有手机日历都能正确识别单双周，脚本直接把每次上课的日期算出来。6 门课一学期约 60 条，手机完全没压力。

**Q：时区会不会错？**
不会。生成时把北京时间换算成 UTC（带 `Z` 后缀）写入，任何日历都会正确换算回当地时间。早期版本写的是「浮动本地时间」，部分手机会整体偏 8 小时，已修。

**Q：PDF 里能认出课表，但课程少了一门？**
先跑 `python pdf转表格.py 课表.pdf` 看 CSV：如果那门课在 CSV 里是空白的，说明 PDF 里这格的文字被拆散了（常见于合并单元格）。可以直接改 CSV / 课表.txt 补上，再生成。识别逻辑和网页版完全一致，两边结果可以对拍。

**Q：学期开始日期从哪来？**
全自动模式会从教务系统页面读取「第 X 周 / 共 Y 周」，自动反推第一周周一，并写进 `课表_抓取.txt`；
手动模式和 PDF 模式则读 `课表.txt` 里的 `学期开始: YYYY-MM-DD`，或命令行 `--start`。

**Q：抓错了怎么办？**
打开 `课表_抓取.txt` 看一眼，它就是普通文本，改完再运行 `python 课表转日历.py 课表_抓取.txt` 即可。

## 目录

```
课表转日历/
├── 一键-抓取并生成.bat   全自动入口（推荐）
├── 抓课表.js             从教务系统网页抓表格 → 课表_抓取.txt
├── 课表转日历.py         课表文本 / PDF → .ics（文本模式零依赖）
├── pdf课表识别.py        PDF 识别核心（PyMuPDF：坐标还原表格）
├── pdf转表格.py          PDF → CSV / Excel / 课表文本
├── PDF转表格.bat         把 PDF 拖到它上面即可导出表格
├── 课表.txt              手动模式的课表（也是学期开始日期的配置）
├── 一键-生成日历.bat     手动模式入口（可直接把 PDF 拖到它上面）
├── 我的课表.ics          生成结果（示例，课程为虚构数据）
├── 样例/
│   ├── 演示课表.html     用于测试抓取效果的仿真页面
│   └── 示例输出.ics      示例生成结果
└── README.md
```

## 环境要求

- **自动抓取**：Windows + Node.js 22+ + `playwright-core` + Microsoft Edge
- **生成日历（文本）**：Python 3.9+（只用标准库，无需 pip 安装）
- **生成日历（PDF）**：额外 `pip install pymupdf`；要出 Excel 再加 `pip install openpyxl`
- **网页版**：任意现代浏览器（iOS Safari / Chrome / 微信内置浏览器）
